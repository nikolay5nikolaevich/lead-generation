# Этап $ARGUMENTS

1. Прочитай `stages/stage-0$ARGUMENTS.md`. Если номер двузначный, поправь имя файла.
2. Прочитай `PROGRESS.md`. Предыдущий этап не закрыт — сначала закрой его.
3. Прочитай разделы `SPEC.md`, перечисленные в файле этапа.
4. Прочитай код, который этап меняет, и реализуй задание.
5. Запусти команды приёмки и покажи вывод. Не совпал с ожидаемым — чини,
   этап не закрыт.
6. Удали временные файлы. Допиши блок этапа в `PROGRESS.md` по формату из его шапки.
